## What it does

`main.ts` (Node 22) writes one original sentence — the funniest excuse a robot
vacuum can give for missing a spot — to `/output/entry.txt`. The line is a
single sentence of at most 200 characters, told deadpan in the vacuum's own
first-person voice, with the punch at the end.

## Run it

```sh
node main.ts
```

It writes `entry.txt` to `/output` by default; set `MAKEFUN_OUTPUT_DIR` to
write somewhere else (for example, for a local check).
